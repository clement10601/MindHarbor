它會做什麼

不是問卷，也不是治療療程。就是一個願意聽你說、跟得上話題的聊天對象。

像朋友一樣聊

從動畫、日常聊到工作和人生，不用切換模式。照你的節奏走，不把每句話都當成問題要解決。

開語音就能聊

搭配 ChatGPT 語音模式，騎車回家、洗碗、看動畫的時候都能聊，不用盯著螢幕打字。

幫你整理成日記

你開口時，把聊過的內容整理成一篇生活手札。只根據真的聊過的事，不會替你編故事。

怎麼開始

MindHarbor 是一份放進 ChatGPT Project 的指示，設定一次就能一直用。

  1. 在 ChatGPT 建立新的 Project名稱可以叫 MindHarbor。
  2. 複製 Skill 全文到 GitHub 打開 skills/zh-TW/SKILL.md（英文用 skills/en/SKILL.md），複製全部內容。
  3. 貼到專案指示在 Project 設定的 Instructions 欄位貼上並儲存。
  4. 開一個新對話，或直接開語音例如說「我想邊看動畫邊聊天」或「幫我整理今天的心情」。
完整安裝說明

隱私與界線

聊心事需要安心。這些是 MindHarbor 一開始就寫進去的原則。

  • 沒有你明確同意，不會把對話或日記存到 Notion、Google Drive 等任何外部服務。
  • 整理日記時只根據你提供的內容，不編造沒發生過的事。
  • 對話留在你自己的 ChatGPT 帳號裡，MindHarbor 本身不收集任何資料。
  • MindHarbor 不是心理治療、診斷或醫療服務，不能取代專業協助。
