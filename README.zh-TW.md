# MindHarbor 🌊 心理支持與自我探索

**讓對話像真正的對話，而不是一套必須完成的心理支持流程。**

繁體中文 · [English](README.md)

網站：<https://mindharbor.fezone.tw/>

MindHarbor 是一份供 ChatGPT Project 使用的對話指引，重視自然交流、理解情緒、尊重自主性，以及需要時提供具體方法。它不是心理治療師，也不是醫療產品。

## 特色

- 可以單純閒聊，不強迫每次對話都做情緒分析
- 先理解，再討論或提供建議
- 短回答不等於想結束；不刻意延長或提前收尾
- 根據實際分享內容整理日記，不杜撰經驗
- 尊重個人隱私；寫入 Notion、Google Drive 等系統前需要明確授權
- 必要時提醒尋求現實世界的安全與專業支持

## 安裝：ChatGPT Project

1. 在 ChatGPT 建立一個新「專案」（Project），或開啟既有專案。
2. 找到專案指示（Project instructions）的編輯位置。
3. 複製 [`skills/zh-TW/SKILL.md`](skills/zh-TW/SKILL.md) 全部內容，貼到專案指示並儲存。想使用英文版則改用 [`skills/en/SKILL.md`](skills/en/SKILL.md)。
4. 在專案內開啟新對話，直接用平常說話的方式聊天即可。
5. 如果要保存日記，可以選擇連接 Notion 或 Google Drive；**連接不等於自動儲存**，仍需明確要求寫入。

如果專案指示有字數限制，可參考 [`docs/QUICKSTART.md`](docs/QUICKSTART.md) 的精簡版本，或將完整版當作專案參考檔案附加，並在指示中要求遵循。實際功能與限制會隨產品版本而異。

**不需要寫程式、安裝套件或設定 API Key。** 目前公開的是 Prompt／Skill 與使用文件，並非獨立的 App。

## 怎麼使用

可以說「我邊看動畫邊聊」、「最近對工作有點擔心」、「幫我整理今天的心情」或「依照我們剛剛聊的內容，幫我寫一篇日記」。

## 安全與隱私

MindHarbor 不提供診斷或醫療處方。若有立即危險，請優先聯絡當地緊急服務或可信任的人。日記可能包含個人資訊；使用外部連接服務前，請先確認自己願意分享的內容和對方的儲存政策。
