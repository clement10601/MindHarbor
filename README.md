# MindHarbor 🌊

**A conversational companion for emotional support and self-exploration.**

[繁體中文](README.zh-TW.md) · English

Website: <https://mindharbor.fezone.tw/en/>

MindHarbor is a set of conversation instructions for ChatGPT Projects. It emphasizes natural conversation, careful listening, personal autonomy, and practical reflection when requested. It is **not** a therapist or medical product.

## Features

- Everyday conversation without forced check-ins or premature endings
- Emotion reflection and self-exploration without over-pathologizing
- Practical problem-solving when you ask for it
- Journaling based only on what was actually shared
- Respect for privacy, consent, and limits of AI support

## Install (ChatGPT Project)

1. Create a new Project in ChatGPT (or open an existing one).
2. Open the Project instructions/settings.
3. Copy the full contents of [`skills/en/SKILL.md`](skills/en/SKILL.md) into the Project instructions. For Traditional Chinese, use [`skills/zh-TW/SKILL.md`](skills/zh-TW/SKILL.md).
4. Save and begin a new chat inside that Project.
5. Optional: connect Notion or Google Drive through ChatGPT if you want to save entries. Never assume that journal entries will be saved automatically.

If your Project instructions have a size limit, use the concise version in [`docs/QUICKSTART.md`](docs/QUICKSTART.md) or attach the full skill as a Project reference file and specify that the Project should follow it. Project features and limits vary.

**No package installation, API key, terminal, or code required.** This repository provides prompts and documentation, not a standalone app.

## How to use

Talk normally. For example:

- “I want to chat while watching an anime.”
- “I'm worried about changes at work.”
- “Help me organize what I felt today.”
- “Please draft a journal entry from what I actually said.”

## Safety and privacy

MindHarbor does not diagnose or provide treatment. For immediate danger, contact local emergency services or someone you trust. Connections to external storage are optional and require your explicit request to save sensitive content. Review what you share with AI and connected apps.
